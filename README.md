# Yahoo!ニュース Discord通知＆AI要約・音声読み上げボット (Yahoo! News Bot)

Yahoo!ニュースの最新記事を自動でパトロールし、新着記事が投稿された瞬間にGoogleの最新AI（Gemini）で自動要約した上で、Discordへの通知・Excelへの記録・パソコンのスピーカーからの音声自動読み上げをすべて同時に行う超多機能な自動化アプリケーションです。

## 📝 アプリの説明

このアプリは、Pythonの強力なスクレイピング技術を活用し、指定された間隔でYahoo!ニュースを監視します。
前回のチェック時と異なる「新しい記事」を検知すると、その記事の本文を自動取得し、Googleの無料AI（Gemini）が3行のシンプルな箇条書きに要約します。
要約されたニュースは、Discordに通知され、Excelファイルへ自動記録されると同時に、**あなたのパソコンのスピーカーからタイトルとAI要約を滑らかな日本語で自動で読み上げます。**
さらに、Gemini が記事内容を解析し、社会的インパクトを 0〜100 の **重要度スコア** として数値化します。

### ✨ 主な機能と特徴
- **簡単ダブルクリック起動**: コマンド入力をせず、バッチファイル（`run.bat`）から一発で起動できます。
- **音声自動読み上げ機能**: 起動時と新着ニュース検知時に、タイトルとAI要約をスピーカーから自動で喋ります。
- **AI自動3行要約**: 記事を開かなくても、ニュースの要点が数秒で分かります。
- **Excel自動ログ記録**: 通知したニュースを自動でExcelに追記保存し、自分だけのニュースデータベースを構築できます。
- **Excel自動グラフ化**: 蓄積したデータからカテゴリ別の比率を計算し、**円グラフ付きの集計レポートを自動生成**します。
- **カテゴリ切り替え**: 設定ファイルを書き換えるだけで、取得するニュースジャンルを自由に変更できます。
- **パトロール間隔の調整**: 監視スピード（秒数）を設定ファイルから自由に変更できます。
- **狙い撃ちキーワード機能**: 特定の単語を含むニュースだけを通知・読み上げできます。
- **セマンティック関心ワード判定**: AI が記事内容を理解し、興味のあるテーマに近いニュースだけを通知できます。
- **重複通知の防止**: 同じ記事を何度も通知・記録・朗読しない安全設計です。
- **過去ログ連動型の重複通知防止**: 再起動時に `news_log.xlsx` を読み込み、既読記事をスキップします。
- **HTTP通信の自動再試行（指数バックオフ）**: 通信エラー時に最大5回まで自動再試行し、安定したスクレイピングを実現します。
- **設定値の自動バリデーション（Pydantic）**: `config.txt` の誤設定を起動時に検出し、安全に起動します。
- **サービス分離による高い保守性**: スクレイピング・AI要約・Excel処理・Discord通知・音声読み上げを完全に分離し、拡張性と安定性が向上しました。
- **メインループの責務最小化**: `yahoo_news_notifier.py` はサービスを呼び出すだけのシンプル構造になり、見通しが大幅に改善されました。
- **AI重要度スコア（0〜100）**: Gemini が記事の社会的インパクトを評価し、Discord と Excel に「重要度: 82/100」のように表示します。

## 🚀 アプリの使い方

### 1. 設定ファイルの作成と設定

#### 📝 config.txt の作成
このリポジトリをクローン時には **`config.txt`** は含まれていません。以下の手順で新規作成してください。

1. **プログラムと同じフォルダ（ディレクトリ）内に `config.txt` という新規ファイルを作成します。**
   - Windows: エクスプローラで右クリック → 新規作成 → テキストドキュメント → 名前を `config.txt` に変更
   - または、メモ帳を開いて → 名前をつけて保存 → `config.txt` として保存

2. **以下の設定項目をテンプレートとしてコピーして、ファイルに貼り付けます。**

```text
# Discord通知ボットの設定ファイル（#で始まる行はコメントとして無視されます）

DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/XXXXXX/XXXXXX
GEMINI_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
CATEGORY=it,business,science
KEYWORDS=Python,AI,iPhone
AI_SUMMARY_ENABLED=true
SEMANTIC_INTEREST=ガジェットの最新技術
SEMANTIC_THRESHOLD=80
CHECK_INTERVAL=60
```

3. **各項目に自分の環境に合わせた値を設定して保存します。**
   - *※ `=` の前後にスペース（空白）を入れずに記述してください。*

#### 💡 各設定項目の詳細
- **`DISCORD_WEBHOOK_URL=`** : 通知を送りたいDiscordチャンネルのWebhook URLを入力します（必須）。
  - 取得方法: Discord > サーバー設定 > 連携機能 > ウェブフック > 新規ウェブフック作成から URL をコピー
- **`CATEGORY=`** : 以下の設定値（英語）を記述してジャンルを変更できます。複数指定する場合はカンマ区切りで入力してください。空欄、または行ごと削除した場合は、自動的に **「総合・主要」** のニュースをパトロールします。


| 設定値（英語） | ニュースのジャンル |
| :--- | :--- |
| **`it`** | IT・科学 |
| **`domestic`** | 主要・国内（未設定時のデフォルト） |
| **`world`** | 国際 |
| **`business`** | 経済 |
| **`entertainment`** | エンタメ |
| **`sports`** | スポーツ |
| **`local`** | 地域 |

- **`KEYWORDS=`** : 通知してほしい特定の単語を記述します。
  - 半角カンマ（`,`）で区切って入力すると、**どれか1つでも含まれていたら通知**する（OR検索）ようになります（例: `Python,AI`）。
  - 空欄にするか行ごと削除すると、すべての新着ニュースを通知・読み上げします。
  - 注: キーワード指定時は、キーワードマッチが優先されます。セマンティック関心と組み合わせて使うことはできません。
- **`GEMINI_API_KEY=`** : Google AI Studioで取得した無料のAPIキーを入力します。
  - 取得方法: [Google AI Studio](https://aistudio.google.com/app/apikey) にアクセス → "API キーを作成" で新規キーを生成してコピー
  - `AI_SUMMARY_ENABLED=true` かつ `GEMINI_API_KEY` が設定されていて初めて、記事の要約機能が動作します。
- **`AI_SUMMARY_ENABLED=`** : AI要約機能を有効/無効にします。
  - `true` / `1` / `yes` / `on` を設定すると有効になります（詳細は上記 `GEMINI_API_KEY` を参照）。
  - `false` / 空欄の場合は無効で、記事の要約・音声読み上げは実行されません。
- **`SEMANTIC_INTEREST=`** : 関心のあるテーマを文章で指定します。例: `ガジェットの最新技術` や `副業に役立つ経済知識`。
  - この項目を設定すると、Geminiがニュースタイトルと本文をユーザーの関心と比較し、関連度を判定します。
  - `GEMINI_API_KEY` が設定されていない場合は無視されます。
  - 注: `KEYWORDS` が指定されている場合、セマンティック判定は行われません。
- **`SEMANTIC_THRESHOLD=`** : セマンティックスコアのしきい値を 0 〜 100 で指定します。
  - 高い値ほど絞り込みが厳しくなり、関心に強く一致するニュースのみを通知します。デフォルトは `80` です。
- **`CHECK_INTERVAL=`** : ニュースをチェックしに行く間隔を **「秒数」** で指定します。（デフォルトは `60` 秒）。

### 2. アプリケーションの実行
プログラムと同じフォルダ内にある **`run.bat`** ファイルをダブルクリックします。

自動的にコマンドプロンプトが立ち上がり、現在の設定内容が日本語で画面に表示されます。
起動した瞬間に、パソコンから現在の最新ニュースの読み上げが始まり、Discordへ初回テスト通知が届いたら自動パトロールのスタートです。

### 🗄️ 3. Excelデータベース（news_log.xlsx）の確認
新着ニュースを検知するたびに、同じフォルダ内に **`news_log.xlsx`** というExcelファイルが自動生成（または追記）されます。このファイルには、以下の2つのシートが自動的に作成されます。

1. **`News Log` シート**: 「通知日時」「カテゴリ」「タイトル」「記事URL」「AI要約内容」「重要度スコア」が1行ずつ蓄積されていくメインのデータベースです。
2. **`集計レポート` シート**: これまで通知されたニュースのカテゴリ比率を集計し、**最新の「円グラフ」をリアルタイムで自動描画・更新**するシートです。

*※注意: プログラムが動いている最中にこのExcelファイルを開いたままにしていると、Pythonが新着データの追記やグラフの更新、さらには「過去ログの重複チェック」ができずにエラーとなってしまうため、確認した後は必ずExcelを閉じておいてください。*


### 🛑 停止する方法
アプリの実行を終了したい場合は、起動した黒い画面（コマンドプロンプト）を選択した状態で、キーボードの以下のショートカットキーを押してください。
- **Windows / Mac 共通**: `Ctrl + C`

```text
├── yahoo_news_notifier.py      # メインループ（サービスを呼び出すだけ）

├── config.txt                  # 設定ファイル（カテゴリ・キーワード・AIキーなど）
├── run.bat                     # 自動起動バッチ
│
├── services/                   # ← 新しく追加されたサービス群
│   ├── scraping_service.py     # Yahooニュース取得・本文抽出
│   ├── ai_service.py           # Gemini要約・セマンティック判定・重要度スコア算出
│   ├── excel_service.py        # Excel書き込み・重複チェック・グラフ生成
│   ├── discord_service.py      # Discord通知
│   └── speech_service.py       # 音声読み上げ
│
├── utils/
│   └── http.py                 # HTTP通信（再試行・バックオフ）
│
├── tests/
│   └── test_all_services.py    # 全サービス統合テスト
│
├── news_log.xlsx               # Excelログ（自動生成）
└── README.md                   # 説明書（本ファイル）
```
