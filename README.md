# Yahoo!ニュース Discord通知＆AI要約・音声読み上げボット (Yahoo! News Bot)

Yahoo!ニュースの最新記事を自動でパトロールし、新着記事が投稿された瞬間にGoogleの最新AI（Gemini）で自動要約した上で、Discordへの通知・Excelへの記録・パソコンのスピーカーからの音声自動読み上げをすべて同時に行う超多機能な自動化アプリケーションです。

## 📝 アプリの説明

このアプリは、Pythonの強力なスクレイピング技術を活用し、指定された間隔でYahoo!ニュースを監視します。
前回のチェック時と異なる「新しい記事」を検知すると、その記事の本文を自動取得し、Googleの無料AI（Gemini）が3行のシンプルな箇条書きに要約します。
要約されたニュースは、Discordに通知され、Excelファイルへ自動記録されると同時に、**あなたのパソコンのスピーカーからタイトルとAI要約を滑らかな日本語で自動で読み上げます。**

### ✨ 主な機能と特徴
- **簡単ダブルクリック起動**: コマンド入力をせず、バッチファイル（`run.bat`）から一発で起動できます。
- **音声自動読み上げ機能**: 起動時と新着ニュース検知時に、タイトルとAI要約をスピーカーから自動で喋ります。作業中で画面を見ていなくても耳でニュースを消化できます。
- **AI自動3行要約**: リンクを踏んで記事を読みに行かなくても、ニュースの要点が数秒で分かります。
- **Excel自動ログ記録**: 通知したニュースのデータを自動でExcelに追記保存。自分だけのニュースデータベースが作れます。
- **カテゴリの切り替え**: 設定ファイルを書き換えるだけで、お好みのニュースジャンルに変更可能です。
- **パトロール間隔の調整**: 監視スピード（秒数）を、プログラムをいじらずに自由に変更できます。
- **狙い撃ちキーワード機能**: 自分が興味のある特定の単語が含まれるニュースだけを厳選して通知・読み上げできます。
- **重複通知の防止**: すでに通知済みの同じ記事を何度も送信・記録・朗読しない安全設計。
- **エラーハンドリング**: 通信エラーやAIの制限が発生しても、プログラムが強制終了せずに動き続けるタフな設計です。
- **Excel自動ログ記録＆自動グラフ化**: 通知したニュースのデータを自動でExcelに追記保存。さらに、溜まったデータからカテゴリ別の比率を計算し、**見やすい円グラフ付きの「集計レポート」をリアルタイムで自動生成**します。自分だけのニュースデータベースが視覚的に作れます。

## 🚀 アプリの使い方

### 1. 設定ファイルの書き換え
プログラムと同じフォルダ（ディレクトリ）内にある **`config.txt`** をメモ帳などで開きます。
用意されている各項目に、それぞれ値を設定して上書き保存します。

```text
# Discord通知ボットの設定ファイル（#で始まる行はコメントとして無視されます）

DISCORD_WEBHOOK_URL=https://discord.com...（あなたのWebhook URLをここに貼り付け）
CATEGORY=it
KEYWORDS=Python,AI,iPhone
GEMINI_API_KEY=AIzaSy...（あなたのGemini APIキーをここに貼り付け）
CHECK_INTERVAL=60
```
*※ `=` の前後にスペース（空白）を入れずに記述してください。*

#### 💡 各設定項目の詳細
- **`DISCORD_WEBHOOK_URL=`** : 通知を送りたいDiscordチャンネルのWebhook URLを入力します（必須）。
- **`CATEGORY=`** : 以下の設定値（英語）を記述してジャンルを変更できます。空欄、または行ごと削除した場合は、自動的に **「総合・主要」** のニュースをパトロールします。


| 設定値（英語） | ニュースのジャンル |
| :--- | :--- |
| **`it`** | IT・科学 |
| **`domestic`** | 主要・国内（未設定時のデフォルト） |
| **`world`** | 国際 |
| **`business`** | 経済 |
| **`entertainment`** | エンタメ |
| **`sports`** | スポーツ |
| **`local`** | 地域 |

- **`KEYWORDS=`** : 通知してほしい特定の単語を記述します。
  - 半角カンマ（`,`）で区切って入力すると、**どれか1つでも含まれていたら通知**する（OR検索）ようになります（例: `Python,AI`）。
  - 空欄にするか行ごと削除すると、すべての新着ニュースを通知・読み上げします。
- **`GEMINI_API_KEY=`** : Google AI Studioで取得した無料のAPIキーを入力します。
  - キーを入力すると自動的に「AI要約モード」および「要約の音声読み上げ」が有効になります。空欄にした場合は通常通知として動作します。
- **`CHECK_INTERVAL=`** : ニュースをチェックしに行く間隔を **「秒数」** で指定します。（デフォルトは `60` 秒）。

### 2. アプリケーションの実行
プログラムと同じフォルダ内にある **`run.bat`** ファイルをダブルクリックします。

自動的にコマンドプロンプトが立ち上がり、現在の設定内容が日本語で画面に表示されます。
起動した瞬間に、パソコンから現在の最新ニュースの読み上げが始まり、Discordへ初回テスト通知が届いたら自動パトロールのスタートです。

### 🗄️ 3. Excelデータベース（news_log.xlsx）の確認
新着ニュースを検知するたびに、同じフォルダ内に **`news_log.xlsx`** というExcelファイルが自動生成（または追記）されます。このファイルには、以下の2つのシートが自動的に作成されます。

1. **`News Log` シート**: 「通知日時」「カテゴリ」「タイトル」「記事URL」「AI要約内容」が1行ずつ蓄積されていくメインのデータベースです。
2. **`集計レポート` シート**: これまで通知されたニュースのカテゴリ比率を集計し、**最新の「円グラフ」をリアルタイムで自動描画・更新**するシートです。

*※注意: プログラムが動いている最中にこのExcelファイルを開いたままにしていると、Pythonがデータを追記・グラフ更新できずにエラーとなってしまうため、確認した後は必ずExcelを閉じておいてください。*


### 🛑 停止する方法
アプリの実行を終了したい場合は、起動した黒い画面（コマンドプロンプト）を選択した状態で、キーボードの以下のショートカットキーを押してください。
- **Windows / Mac 共通**: `Ctrl + C`

├── config.txt              # 設定ファイル（URL、カテゴリ、キーワード、AIキー、間隔を記述）
├── run.bat                 # 自動起動用のバッチファイル
├── news_log.xlsx           # 自動生成されるExcelデータベースファイル（起動後に作成されます）
