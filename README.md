# Yahoo!ニュース Discord通知＆AI要約・ログ蓄積ボット (Yahoo! News Discord & AI Notifier)

Yahoo!ニュースの最新記事を自動でパトロールし、新着記事が投稿された瞬間にGoogleの最新AI（Gemini）で自動要約した上で、Discordへの即座な通知と、Excelデータベースへの自動記録を行う超多機能Pythonアプリケーションです。

## 📝 アプリの説明

このアプリは、Pythonの強力なスクレイピング技術を活用し、指定された間隔でYahoo!ニュースを監視します。
前回のチェック時と異なる「新しい記事」を検知すると、その記事の本文を自動取得し、Googleの無料AI（Gemini）が3行のシンプルな箇条書きに要約します。
要約されたニュースは、Discordの **Webhook機能** を通じてチャンネルに通知されると同時に、同じフォルダ内の **Excelファイルへ自動で1行ずつ蓄積（データベース化）** されます。

### ✨ 主な機能と特徴
- **簡単ダブルクリック起動**: コマンド入力をせず、バッチファイル（`run.bat`）から一発で起動できます。
- **AI自動3行要約**: リンクを踏んで記事を読みに行かなくても、Discord上でニュースの要点が数秒で分かります。
- **Excel自動ログ記録**: 通知したニュースのデータを自動でExcelに追記保存。自分だけのニュースデータベースが作れます。
- **カテゴリの切り替え**: 設定ファイルを書き換えるだけで、お好みのニュースジャンルに変更可能です。
- **パトロール間隔の調整**: 監視スピード（秒数）を、プログラムをいじらずに自由に変更できます。
- **狙い撃ちキーワード機能**: 自分が興味のある特定の単語が含まれるニュースだけを厳選して通知できます。
- **重複通知の防止**: すでに通知済みの同じ記事を何度も送信・記録しない安全設計。
- **エラーハンドリング**: 通信エラーやAIの制限が発生しても、プログラムが強制終了せずに動き続けるタフな設計です。

## 🚀 アプリの使い方

### 1. 設定ファイルの書き換え
プログラムと同じフォルダ（ディレクトリ）内にある **`config.txt`** をメモ帳などで開きます。
用意されている各項目に、それぞれ値を設定して上書き保存します。

```text
# Discord通知ボットの設定ファイル（#で始まる行はコメントとして無視されます）

DISCORD_WEBHOOK_URL=https://discord.com...（あなたのWebhook URLをここに貼り付け）
CATEGORY=it
KEYWORDS=Python,AI,iPhone
GEMINI_API_KEY=AIzaSy...（あなたのGemini APIキーをここに貼り付け）
CHECK_INTERVAL=60
```
*※ `=` の前後にスペース（空白）を入れずに記述してください。*

#### 💡 各設定項目の詳細
- **`DISCORD_WEBHOOK_URL=`** : 通知を送りたいDiscordチャンネルのWebhook URLを入力します（必須）。
- **`CATEGORY=`** : 以下の設定値（英語）を記述してジャンルを変更できます。空欄、または行ごと削除した場合は、自動的に **「総合・主要」** のニュースをパトロールします。


| 設定値（英語） | ニュースのジャンル |
| :--- | :--- |
| **`it`** | IT・科学 |
| **`domestic`** | 主要・国内（未設定時のデフォルト） |
| **`world`** | 国際 |
| **`business`** | 経済 |
| **`entertainment`** | エンタメ |
| **`sports`** | スポーツ |
| **`local`** | 地域 |

- **`KEYWORDS=`** : 通知してほしい特定の単語を記述します。
  - 半角カンマ（`,`）で区切って入力すると、**どれか1つでも含まれていたら通知**する（OR検索）ようになります（例: `Python,AI`）。
  - 空欄にするか行ごと削除すると、すべての新着ニュースを通知します。
- **`GEMINI_API_KEY=`** : Google AI Studioで取得した無料のAPIキーを入力します。
  - キーを入力すると自動的に「AI要約モード」が有効になります。空欄にした場合は通常通知として安全に動作します。
- **`CHECK_INTERVAL=`** : ニュースをチェックしに行く間隔を **「秒数」** で指定します。
  - 5分ごとにしたい場合は `300`、10分ごとにしたい場合は `600` のように数字を入力します（デフォルトは `60` 秒）。
  - 空欄、または数字以外が入力された場合は、安全のために自動的に `60` 秒にセットされます。

### 2. アプリケーションの実行
プログラムと同じフォルダ内にある **`run.bat`** ファイルをダブルクリックします。

自動的にコマンドプロンプトが立ち上がり、必要なフォルダへの移動とプログラムの実行が開始されます。
画面に `📡 ニュースのパトロールを開始しました` と表示され、初回テスト通知（3行要約付き）が届いたら自動監視のスタートです。

### 🗄️ 3. Excelデータベース（news_log.xlsx）の確認
新着ニュースを検知するたびに、同じフォルダ内に **`news_log.xlsx`** というExcelファイルが自動生成（または追記）され、「通知日時」「カテゴリ」「タイトル」「記事URL」「AI要約内容」が自動で美しく蓄積されていきます。
*※注意: プログラムが動いている最中にこのExcelファイルを開いたままにしていると、Pythonがデータを追記できずにエラーとなってしまうため、確認した後は必ずExcelを閉じておいてください。*

### 🛑 停止する方法
アプリの実行を終了したい場合は、起動した黒い画面（コマンドプロンプト）を選択した状態で、キーボードの以下のショートカットキーを押してください。
- **Windows / Mac 共通**: `Ctrl + C`
